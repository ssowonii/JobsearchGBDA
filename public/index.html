LinkedIn & Indeed (browser helper)

      
Run in a terminal: npm run browser. A Chrome window opens. Sign in yourself, then browse as you normally would. Every job posting you open is captured here automatically.

      
The optional npm run browser -- search mode runs your saved searches automatically, slowly. LinkedIn's terms forbid automated access, and accounts can be restricted, so capture mode is the safer choice.
